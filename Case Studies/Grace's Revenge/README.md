# COMATOSE - Portfolio Media Library

Project facts currently approved for the public case study:

- Unity capstone project, September 2025 to April 2026
- 15-person multidisciplinary team
- Ekraj's contributions included technical art, environment and interior work, UI implementation, gameplay programming support, lighting, VFX, interactive audio and character movement
- The game uses an open-world structure contained inside a designed building interior
